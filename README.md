# Keycaps

A curated collection of guides, resources, and references for custom mechanical keyboard keycaps.

## Goals
- Collect beginner-friendly guides for buying and customizing keycaps
- Document casting, dye-sublimation, and artisan keycap techniques
- Curate vendor links, profile sheets, and tooling resources
- Provide community-contributed walkthroughs and templates

## Structure
- guides/ — step-by-step tutorials and how-tos
- resources/ — vendor lists, materials, tooling, glossaries
- images/ — photos, diagrams, and reference images
- templates/ — profile templates, spreadsheets, checklists

## Contributing
Please open issues or pull requests for additions or corrections. Consider adding:
- A short summary and difficulty level for each guide
- Links to source materials and licensing info
